# توسعة المملكة — Core v30 / Android 0.6

هذه إضافة إلى السيرفر الموجود، وليست سيرفرًا بديلًا. يجب تثبيتها على جهاز أوبنتو لتفعيل العالم الجديد والتسريعات. لا يستطيع APK وحده إنشاء بيانات دائمة في قاعدة السيرفر.

تضيف للمملكة الأولى:

- 1000 مدينة غير لاعبة، بمواقع وقوة عشوائية ثابتة بعد الإنشاء؛ مدن استكشاف، لا حسابات لاعبين وهمية ولا قتال NPC.
- 2200 نقطة موارد و800 وحش، من خلال جداول الجمع والصيد الحالية؛ تعمل معها المسيرات والتجدد الموجودان في Core v30.
- 12 معلمًا: 4 للتدريب و4 للجمع و4 لقوة الحاكم. التفعيل دائم وخاص بالحساب. كل معلم تدريب/جمع يضيف 5% سرعة؛ الحد الإجمالي 20% لكل نوع. معالم القوة تضيف 2500/5000/7500/10000 نقطة إلى قوة الحاكم، وليست مضاعف ضرر قتالي.
- مستودع التسريعات، وصندوق مجاني مرة واحدة لكل حساب. التسريع يختصر زمن البناء أو التدريب أو البحث ويترك الاستلام للاعب.

## التثبيت على أوبنتو

للحصول على الملفات من المستودع على جهاز أوبنتو:

```bash
git clone --depth 1 https://github.com/faisal912912/strategy-game-android.git frontier-world-update
cd frontier-world-update/server/expansion
```

ثم نفّذ كمستخدم تشغيل السيرفر المعتاد:

```bash
bash install.sh
```

المسار الافتراضي `~/gameserver001`. لتغييره:

```bash
bash install.sh /absolute/path/to/gameserver001 /absolute/path/to/backups
```

المثبّت يحتاج Go وPostgreSQL client وصلاحية إعادة تشغيل خدمتي اللعبة. يختبر ويُجمّع الإضافة مع مصدر Core الفعلي أولًا، ثم يحفظ نسخة من قاعدة البيانات والبرنامج، ويطبّق إضافة الجداول ويزرع المملكة الأولى. لا يغيّر رابط النفق أو إصدار الصحة `core-v30`. يبقى السيرفر الثاني دون مدن عشوائية جديدة.

بعد النجاح، افتح نسخة Android 0.6 ثم **المستودع ← التحقق من التحديث** أو أعد فتح التطبيق. افتح المملكة ثم زر النجوم للمعالم. فعّل المعلم بعد توفير مستوى القلعة والموارد المطلوبة. استلم صندوق التسريعات من المستودع ثم اختر عملًا جاريًا.

## العقد والتوافق

| الطلب | النتيجة |
| --- | --- |
| `GET /api/v1/expansion/v1/world` | المدن غير اللاعبة ومعالم المملكة الحالية |
| `GET /api/v1/expansion/v1/state` | المكافآت، المعالم المفعّلة، حالة الصندوق، معرفات أعمال المدينة وأوقاتها |
| `POST /api/v1/expansion/v1/starter-claim` | الصندوق المجاني مرة واحدة |
| `POST /api/v1/expansion/v1/claim-landmark` | `{landmark_id}`؛ خصم غذاء وخشب وتفعيل المعلم |
| `POST /api/v1/expansion/v1/speedup` | `{kind,job_id,item_key,count}`؛ `kind`: build/train/research |

جميع الطلبات تستخدم مصادقة Core. الأوامر تتطلب `X-Idempotency-Key`؛ حفظ النتيجة والخصم في معاملة PostgreSQL واحدة. إعادة نفس الأمر لا تكرر الصرف. رفض العمل المكتمل، العدد الزائد، النوع غير المناسب أو عمل لاعب آخر لا يخصم عنصرًا.

تطبق مكافأة التدريب على أعمال التدريب الجديدة، والجمع على مدة الجمع للمسيرات الجديدة. الصيغة `duration / (1 + bonus / 100)`؛ اختصار الوقت يختلف حسابيًا عن نسبة زيادة السرعة. لا تتغير المسيرات أو الأعمال السابقة عند التفعيل.

يمكن إعادة تشغيل التثبيت؛ البذر لا يغيّر المدن الموجودة أو يعيد ملء نقطة موارد مستنزفة. لا تستخدم الاستعادة الكاملة لنسخة قاعدة البيانات أثناء لعب المستخدمين: ستعيد كل البيانات إلى وقت النسخ. للاطلاع على النسخة السابقة، يستخدم المثبّت مجلدًا مؤرخًا يطبعه عند التنفيذ.

## الاختبار

`validation/run.sh` يختبر الإضافة على PostgreSQL مع مخطط اختباري مشتق من جداول Core v2/v5/v12/v15/v16. يرفض أي اسم قاعدة غير `frontier_expansion_test`. يشمل ثبات المدن، عدم تداخلها، عزل الممالك، خصم العناصر، التكرار المتزامن، ملكية الطوابير، متطلبات المعالم وتأثيرات الزمن والقوة. محول المصادقة في الاختبارات بديل محلي؛ المثبّت هو الذي يتحقق من التجميع مع مصدر Core الفعلي. لم تُنشر الإضافة على أوبنتو من هذه المحادثة.
